# 🚗 منصة زيوت السيارات الذكية - Professional MCP System

## 🌟 نظرة عامة

منصة متقدمة للموزعين المعتمدين لزيوت السيارات، مدعومة بتقنيات **MCP (Model Context Protocol)** والذكاء الاصطناعي **Claude AI**.

## ✨ المميزات الرئيسية

### 🤖 مساعد الذكاء الاصطناعي
- تفاعل ذكي مع المستخدمين عبر Claude AI
- توصيات مخصصة للمنتجات
- إجابة فورية على الاستفسارات
- بحث ذكي وفلترة تلقائية

### 📊 لوحة تحكم متقدمة
- إحصائيات مباشرة للمنتجات
- عرض إجمالي الفئات والأسعار
- تتبع نتائج البحث

### 🔍 نظام بحث وفلترة متطور
- بحث نصي شامل
- فلترة حسب الفئة والحجم والسعر
- خيارات ترتيب متعددة

### 📱 عروض متعددة
1. عرض الجدول - تفصيلي احترافي
2. عرض الشبكة - بطاقات منظمة
3. عرض البطاقات - تصميم حديث

### 🛒 نظام سلة متكامل
- إضافة وتعديل المنتجات
- حفظ تلقائي (Persistent Storage)
- إرسال الطلب عبر WhatsApp

### 📱 Progressive Web App
- قابل للتثبيت
- يعمل بدون إنترنت
- تجربة تطبيق أصلي

## 🚀 التقنيات المستخدمة

- HTML5 + CSS3 + JavaScript
- Claude AI (Sonnet 4)
- MCP Storage API
- Service Worker + PWA

## 📦 الملفات

- index.html - الصفحة الرئيسية
- app.js - منطق التطبيق + MCP
- styles.css - التصميم
- oil_shop_complete.json - قاعدة البيانات
- manifest.json + sw.js - PWA
